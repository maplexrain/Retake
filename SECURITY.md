# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Retake, please do not file a public issue.
Instead, submit a confidential report by creating a [Security Advisory](https://github.com/maplexrain/Retake/security/advisories/new) on GitHub.

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a proof of concept to reproduce the issue.
- Your environment details (Windows version, Retake version).

We will review your submission, patch verified vulnerabilities in a timely manner, and credit responsible disclosure.
